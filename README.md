# Chord Improv Trainer
Chord Improv Trainer is a web app to remind the user of interesting chords while improvising. It takes in real time MIDI data and detects the current chord being played. Based on that data, it suggests future chords to play with an emphasis on non-diatonic/colorful chords. Because it takes practice to come up with both an interesting melody and chords while playing in real time, this web app helps the user a little with thinking of interesting chords. The eventual goal is for the user to practice the suggested non-diatonic chords enough to play them naturally in real time without the aid of the app.

## Run
Requires a MIDI keyboard and browser which supports [Web MIDI API](https://developer.mozilla.org/en-US/docs/Web/API/Web_MIDI_API#browser_compatibility)

Deployment can be found [here](https://chord-improv-trainer.pages.dev)
